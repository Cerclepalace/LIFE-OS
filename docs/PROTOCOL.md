# LIFE-OS Engineering & Research Protocol

## Execution chain

INVENTION CANDIDATE
-> TECHNICAL DECOMPOSITION
-> EXACT SEARCH
-> FUNCTIONAL SEARCH
-> ARCHITECTURAL SEARCH
-> CROSS-DOMAIN SEARCH
-> CLAIM-BY-CLAIM
-> FAMILY / CONTINUATION / CITATIONS
-> DESIGN-AROUND
-> COUNTER-DESIGN-AROUND
-> NEW VARIANT
-> RESEARCH AGAIN
-> SURVIVOR / KILL

## Evidence levels

- FACT: directly verified from a source
- TECH: technical interpretation grounded in evidence
- OVERLAP: comparison against LIFE-OS
- WHITE-SPACE HYPOTHESIS: not found in the current search scope

## Gate discipline

No candidate becomes a strong candidate from conceptual originality alone. A candidate must survive prior-art, functional-equivalent, architecture, and design-around attacks.
