# LIFE-OS

Life Operating System — technical foundation for evidence-grounded personal state, memory, world modeling, decision support, and controlled operational propagation.

## Principles

- Evidence before inference
- Explicit state and provenance
- Temporal traceability
- Auditable transitions
- Human control over consequential actions
- Modular patent/invention family architecture
- No transactional capability by default

## Repository map

- `docs/` — architecture, protocols, research and decisions
- `specs/` — technical specifications
- `research/` — prior-art and invention research
- `src/` — implementation
- `tests/` — validation
- `inventions/` — invention disclosures and patent-family candidates

See `docs/ARCHITECTURE.md` for the current system model.
